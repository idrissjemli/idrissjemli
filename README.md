## Featured projects

### 🏦 [biat-monitoring](https://github.com/idrissjemli/biat-monitoring)
Real-time monitoring platform for card payment transactions, built end to end during my final-year project at BIAT IT.
Star-schema warehouse on SQL Server, Python ETL over **1M+ transactions**, Isolation Forest anomaly detection, Power BI dashboards, and a RAG assistant for querying indicators in natural language.
Fully containerised — runs with a single `docker compose up`.

`Python` · `Flask` · `Angular` · `SQL Server` · `Scikit-learn` · `Power BI` · `Docker`

### 🔀 [ssis-etl-qualite-donnees](https://github.com/idrissjemli/ssis-etl-qualite-donnees)
SSIS pipeline that loads a flat file into a warehouse while **separating valid rows, business rejects and technical errors** into three distinct tables — so no record is ever silently lost.
Idempotent by design, with type conversion, normalisation and dimension lookup.

`SSIS` · `SQL Server` · `T-SQL` · `Data Quality`

### 🏠 [gestion-foyer-universitaire](https://github.com/idrissjemli/gestion-foyer-universitaire)
University housing management system — REST API, role-based access control, JUnit test suite.

`Java 17` · `Spring Boot` · `JPA` · `MySQL` · `Spring Security`
